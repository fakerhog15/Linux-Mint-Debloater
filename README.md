## 🚀 Overview

**Linux Mint Debloater** is designed to clean up a fresh installation of Linux Mint. While Mint is an excellent operating system, it comes with several pre-installed applications and packages that you might not need. This script helps you safely remove that "bloat," freeing up system resources, reducing background processes, and keeping your application menu clean.

## ✨ Features

* **Lightweight:** Removes unnecessary default applications (e.g., specific media players, unused system tools).
* **Resource Friendly:** Frees up disk space and reduces RAM usage.
* **Customizable:** Easy to edit the script to keep the apps you actually use.
* **Safe:** Targets non-essential user-space applications to ensure your system remains completely stable.

## ⚠️ Disclaimer

**Please review the script before running it.** 
What one person considers "bloatware," another might consider essential. It is highly recommended to open the script in a text editor, read through the list of packages marked for removal, and comment out (`#`) anything you want to keep. 

*Use at your own risk. It is always best practice to create a Timeshift backup before making bulk changes to your system packages.*
